# Cargo Load MVP

Небольшой проект для оценки загрузки кузова по фотографии. Модель прогнозирует процент заполненности в диапазоне от 0 до 100.

## Задача

По входному изображению нужно определить, насколько заполнен кузов транспортного средства. Это регрессионная задача, где целевая переменная — `load_pct`.

## Что в проекте

- обучение моделей на изображениях;
- GroupKFold для корректного разбиения по группам;
- регрессионная сеть на основе `timm` backbones;
- метрики MAE и Accuracy@10;
- сохранение OOF-прогнозов;
- ансамблирование нескольких моделей в итоговый `submission.csv`.

## Структура репозитория

```text
.
├── src/                  # исходный код
│   ├── train.py          # обучение модели
│   ├── dataset.py        # датасет и аугментации
│   ├── model.py          # backbone + регрессор
│   ├── ensemble.py      # ансамблирование предсказаний
│   └── ...
├── requirements.txt      # зависимости
├── README.md             # документация

```

> В публичном GitHub-репозитории данные, модели и артефакты обучения обычно не кладут в git. Их нужно добавить локально или загрузить в отдельный storage.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Быстрый запуск

Обучение модели:

```bash
python src/train.py \
  --train_csv data/train.csv \
  --groups_csv data/train_groups.csv \
  --images_dir data/images \
  --out_dir models/v1 \
  --backbone efficientnet_b0 \
  --epochs 25 \
  --folds 5
```

Ансамбль нескольких прогонов:

```bash
python src/ensemble.py \
  --runs runs/model_a runs/model_b \
  --test_csv data/test.csv \
  --out submission.csv
```

## Требования к данным

После клонирования репозитория нужно подготовить папку:

```text
data/
├── train.csv
├── train_groups.csv
├── test.csv
├── images/
```

Или использовать другой путь, задаваемый параметрами командной строки.

## Метрики

- MAE — средняя абсолютная ошибка
- Accuracy@10 — доля предсказаний с отклонением не более 10 процентных пунктов
